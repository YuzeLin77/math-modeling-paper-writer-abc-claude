# 语料库：A/B/C 分题型句式 ＋ 口语-书面语对照

> 取自 2022-2025 年 35 篇 A/B/C 一等奖论文原文归纳。同段同义连接词不超过两个。

## 0. 高频词事实（篇均次数，决定该写什么）
- 通用：因此 13.4、基于 10.4、优化（A4.0/B3.9目标函数/C35.2）、进一步 4.0、针对问题 3.7、综上 1.6
- "鉴于"仅 0.17 次/篇，不必刻意用；"本模型"仅 0.19，少用自指。

## 1. A 题（机理优化）语料
- 建系："建立××坐标系，原点取于……，×轴沿……方向"；"通过坐标变换矩阵实现两坐标系转换"。
- 机理："基于反射定律/守恒定律/牛顿第二定律，由××推导得××满足……"；"其物理意义为……"。
- 假设："假设海水无粘、无旋且不可压缩，可采用微幅波理论"；"忽略××，因其在本题时间尺度内变化可忽略"。
- 离散："将××栅格化，取步长 τ=…"；"步长减半，结果变化小于…%，离散精度满足要求"。
- 数值："利用 ode45/trapz 梯形数值积分求解，与解析解对照精度足够"。
- 临界："先以××近似锁定区间，再以二分法/变步长逐步逼近，误差控制在……内"。
- 优化："以××最大化为目标函数，××为决策变量，××为约束，建立单目标优化模型"。
- 互证："采用粒子群复算，两算法相对误差仅 0.01%，验证求解有效性"。
- 分析："散点图峰值移动规律与××物理规律一致"。

## 2. B 题（运筹/几何/决策）语料
- 分类："依据××将问题分为六种排布方式，逐一建模且互不重叠"。
- 几何："在极坐标下通过正弦定理列出三角方程"；"利用几何对称性避开联立方程，降低求解难度"；"通过旋转变换与向量叉积确定圆心"。
- 引理："先提出并证明引理：……，据此反推……"。
- 算法选型："考虑深度优先搜索的效率问题与贪心算法的短视性，在 IDA* 启发下设计带阈值搜索，以 L2 损失为估价函数"。
- 仿真："生成随机仿真样本，方案经 K 轮迭代收敛至 6 位有效数字"；"检验函数由 3.893 降至 0.206，降低 94.7%"。
- 概率决策："次品数服从二项分布，依棣莫弗-拉普拉斯定理近似正态，方差未知故构造 t 分布"；"经 10000 次蒙特卡洛仿真，期望利润为……"。
- 鲁棒："对精确点施加服从正态分布的微扰，取十组数据集，误差随循环次数收敛至 10⁻⁷~10⁻⁵"；"0.95 置信区间内最优决策不变"。

## 3. C 题（数据决策）语料
- 预处理："Shapiro-Wilk 检验表明数据不服从正态分布，传统回归精度下降，故……"；"数据含大量 0，属零膨胀数据，采用同期平均法转化"。
- 关系："××与××呈显著负相关（r=…，P<0.05），符合需求定律/业务机制"；"采用 K-means++ 初始化避免初值敏感，类别数由轮廓系数确定"。
- 预测："经 ADF 检验序列一阶差分后平稳，据 ACF/PACF 定阶为 SARIMA(p,d,q)"；"训练集 R² 达 0.8 以上，测试集 MAPE=…，残差通过白噪声检验"；"多模型横向对比择优"。
- 前沿统计（2025 起）："线性混合效应模型结合 REML 处理重复测量层次结构，通过随机效应必要性、随机截距正态性、同方差检验；ICC 表明 74.3% 变异来自个体差异，AIC 较传统回归改善 17.2%"。
- 优化："以预测值为输入、收益最大化为目标、损耗与陈列量为约束建立优化模型"；"生成 1000 组随机场景，以最大期望准则选抗风险方案"。
- 对比："优化方案较平均情况收益明显提升……"。
- 开放问："建议补充市场均价与竞对定价数据以平衡效益与竞争；补充消费者价格敏感度以把握满意度"。

## 4. 通用承转
- 递进："相较于问题二，问题三新增……，决策空间维数增大，为简化先……"。
- 收敛："算法在第×代收敛，最优值保持稳定"。
- 收尾："本文优点在于……（具体证据）；不足为……（模型边界），可引入……改进；可推广至具有……特征的一类问题"。

## 5. 口语 → 书面语
| 口语 | 书面 |
|---|---|
| 算出 | 求解得到／计算得 |
| 画图看 | 可视化分析表明 |
| 差不多 | 趋于一致，相对误差为 |
| 很重要 | 具有重要现实意义 |
| 效果好 | 精度满足要求／稳健性良好 |
| 调参数 | 参数灵敏度分析 |
| 猜个初值 | 给定初始迭代值并做收敛性检验 |
| 试了好几种算法 | 多模型（算法）横向对比择优 |
| 数据很乱先洗一下 | 数据预处理：缺失值/异常值处理（注明方法与依据） |
| 分了几类 | 依据××聚类，类别数由××准则确定 |
| 跑了很多次仿真 | 蒙特卡洛仿真 N 次，取期望并报告方差 |
| 这么做最赚 | 以期望收益最大化为目标求得最优决策 |
