# 数学建模 A/B/C 题论文写作导师

本项目为个人学习总结的非官方工具，与各种竞赛均无关；内容为对公开获奖论文的方法提炼，未收录任何论文原文。欢迎大家平时学习使用。

数学建模竞赛 A/B/C 题论文写作专用 Skill，基于 2020-2025 年 18 套 A/B/C 真题与 2022-2025 年 35 篇优秀论文（约 158 万字）提炼而成。

## Agent 适配说明

| Agent / 编辑器 | 入口文件 | 使用方式 |
|---|---|---|
| **TRAE** | `SKILL.md` | `Use Skill: math-modeling-paper-writer-abc` |
| **Claude Code** | `CLAUDE.md` | 在包含本文件夹的项目内直接对话，Claude Code 自动读取项目上下文 |
| **Codex / 其他** | `CLAUDE.md` 或 `SKILL.md` | 将对应文件内容作为 system prompt 粘贴使用 |

> 注：写作范式核心内容在 `SKILL.md` 与 `CLAUDE.md` 中保持一致，仅入口格式按不同 Agent 适配。

## 适用场景

- 撰写或修改数学建模 A 题（物理机理类）、B 题（运筹/几何/决策类）、C 题（数据驱动经管类）论文
- 打磨摘要、重构结构、规范图表语言
- 撰写结果分析、灵敏度分析、模型评价
- 针对某道 A/B/C 赛题规划建模与写作路线

## 核心能力

| 模块 | 说明 |
|------|------|
| 判题定位 | 区分 A/B/C 三题基因，给出核心模型链、结果文件清单、技术路线图 |
| 摘要公式 | 四步骨架 + 三类题型变体，确保摘要写出评委想看的数值与逻辑 |
| 全文骨架 | A/B/C 三套标准章节结构，可直接按题型裁剪 |
| 分段写作 | 机理推导、分类讨论、数据预处理、预测建模、优化决策、灵敏度分析等专章指导 |
| 图表规范 | 图题/表题写法、三线表、必备图表类型、正图引用规范 |
| 数字台账 | 强制台账制度，确保摘要、正文、附录、result 文件四处数值一致 |
| 避坑清单 | A/B/C 各题常见失分点与自检项 |

## 使用方式

### TRAE

```
Use Skill: math-modeling-paper-writer-abc
```

### Claude Code

将本文件夹作为项目目录打开（或在任意项目内放置 `CLAUDE.md`），直接发起对话即可，例如：

> "我是 2025 A 题烟幕弹，已经用运动学模型和布尔遮挡判定算完，问题一二用二分法、问题三四五用粒子群+差分进化，结果在 result1-3.xlsx，帮我按 A 题范式写全文，先出大纲和数字台账。"

### 其他 Agent / 手动使用

将 `CLAUDE.md` 或 `SKILL.md` 的全部内容作为 system prompt 粘贴，再提出具体写作需求。

### 调用前请准备好


1. **题位与年份**：哪年、A/B/C 哪题，写全文还是改某段
2. **模型链**：每问用了什么模型/方法
3. **结果数值**：关键结果与对应的 result 文件
4. **交付形态**：Markdown / Word、目标篇幅、是否含公式图表

> 本 Skill 不替用户建模。若结果数据缺失，对应位置会标注 `【待填】`，严禁编造数值。

## 写作底线

- 每个公式必须说清它在原题中的物理/业务含义
- 数值结果只能来自真实计算，没给数的位置留 `【待填】`
- 逻辑闭环五环缺一不可：题目要什么 → 建了什么模型 → 怎么解的 → 结果是多少 → 结果说明什么
- 学术书面语，零口语；方法链用"建立—推导—求解—验证"推进
